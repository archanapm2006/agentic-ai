# Agentic AI Project (React Agent)

An intelligent agentic application built using Python, LangChain, and the Google Gemini API. This project is designed to handle automated reasoning and task execution workflows.

## 🚀 Features

* **Gemini API Integration**: Leverages Google's advanced language models for powerful agentic workflows.
* **Modular Structure**: Clean separation of core application logic and configuration modules.
* **Database Support**: Integrated with SQLite for persistent local data management.
